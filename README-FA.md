# بات خصوصی کانفیگ رایگان — فقط آلمان و آمریکا

بات تلگرام خصوصی برای ساحا. هر ۶ ساعت یک‌بار، با GitHub Actions رایگان، دو سابسکریپشن جدا می‌سازد:
- `de.txt` — فقط آلمان (DE)
- `us.txt` — فقط آمریکا (US)

هر فایل فقط **VLESS+Reality** و **Hysteria2** دارد (TUIC فقط اگر جا ماند). سقف هر فایل ۳۰ نود است.

## این بات چه کار می‌کند و چه کار نمی‌کند

**می‌کند:**
- از Raydikalx (تست‌شده، گروه‌بندی GeoIP بر اساس کشور) و Au1rxx (تست ساعتی) می‌گیرد.
- نود مبهم یا کشور دیگر را حذف می‌کند، حدس نمی‌زند.
- هر ۶ ساعت فایل‌ها را تازه می‌کند و اگر Secretها را گذاشته باشی، خلاصه را در تلگرام می‌فرستد.

**نمی‌کند — صادقانه:**
- **IP ثابت نمی‌دهد.** وقتی یک نود رایگان می‌میرد، نود بعدی همان کشور است ولی IP عوض می‌شود. IP کاملاً ثابت فقط با VPS اختصاصی ممکن است.
- **دستور لحظه‌ای ندارد.** GitHub Actions همیشه روشن نیست؛ پس `/best` ندارد. فقط هر ۶ ساعت و با اجرای دستی آپدیت می‌فرستد.
- **«بهترین برای تو» را از سرور نمی‌داند.** تست بات از سرور GitHub انجام می‌شود، نه از اینترنت تو. بهترین واقعی را Hiddify و Throne با تست پینگ روی گوشی و ویندوز خودت انتخاب می‌کنند.
- **امنیت کامل نمی‌دهد.** نود رایگان یعنی صاحب نود ناشناس است. ترافیک رمزنشده را می‌تواند ببیند.

## راه‌اندازی — ۵ کاری که خودت باید انجام بدهی

### ۱) بات را در BotFather بساز
در تلگرام به `@BotFather` برو، `/newbot` بزن، یک اسم بده. توکن را که می‌دهد **کپی کن و به هیچ‌کس نده** — نه در چت، نه در فایل.

### ۲) ریپوی خصوصی در GitHub بساز و این فایل‌ها را بفرست
- یک ریپوی **Private** بساز، مثلاً `v2ray-bot-de-us`.
- این فایل‌ها را در آن آپلود کن: `fetch.py` ،`README-FA.md` ،`.gitignore` ،`.github/workflows/update.yml`
- `de.txt` ،`us.txt` ،`stats.json` را هم می‌توانی بگذاری؛ ورک‌فلو خودش آن‌ها را می‌سازد و آپدیت می‌کند.

### ۳) Chat ID خودت را بگیر
به بات خودت یک پیام بده (هر چیزی، مثلاً `hi`). بعد در مرورگر این را باز کن — به‌جای `TOKEN` توکن بات را بگذار:
`https://api.telegram.org/botTOKEN/getUpdates`
در جواب، عدد `chat.id` همان Chat ID توست.

### ۴) دو Secret در GitHub بگذار
در ریپو: Settings → Secrets and variables → Actions → New repository secret
- `TELEGRAM_BOT_TOKEN` = توکن بات
- `TELEGRAM_CHAT_ID` = عدد Chat ID
اگر این‌ها را نگذاری، ورک‌فلو باز هم کار می‌کند و فقط فایل‌ها را کامیت می‌کند؛ پیام تلگرام نمی‌فرستد.

### ۵) ورک‌فلو را یک‌بار دستی اجرا کن و لینک‌ها را وارد کن
در ریپو: Actions → Update DE/US subscriptions → Run workflow
بعد از چند دقیقه، دو لینک سابسکریپشن تو این‌ها می‌شوند (به‌جای `USER/REPO` نام کاربری و ریپوی خودت را بگذار):
- آلمان: `https://raw.githubusercontent.com/USER/REPO/main/de.txt`
- آمریکا: `https://raw.githubusercontent.com/USER/REPO/main/us.txt`

## وارد کردن در Hiddify و Throne

**Hiddify (موبایل و ویندوز):**
۱. لینک آلمان و لینک آمریکا را جداگانه به‌عنوان دو سابسکریپشن اضافه کن.
۲. حالت را بگذار **Manual**، نه Auto کلی.
۳. یک نود آلمان یا آمریکا را انتخاب کن و روی همان بمان. وقتی مرد، یک نود دیگر از **همان کشور** را بگیر.
۴. Service Mode را روی **VPN / TUN** بگذار و Kill Switch را روشن کن.

**Throne (ویندوز):**
۱. همان دو لینک را اضافه کن.
۲. **TUN Mode** روشن، **Strict Route** تیک‌خورده، **Kill Switch** روشن باشد.
۳. حالت Manual — Auto Selector را فقط داخل همان کشور استفاده کن، نه روی همه کشورها.

**پروتون رایگان با Stealth** را هم نگه دار؛ وقتی هر دو فایل قطع شدند، پایه وصل‌شدن توست.

## چطور مطمئن شوی کشور درست است؟

بعد از وصل شدن به `ipleak.net` و `dnsleaktest.com` برو:
- IP باید همان کشوری باشد که انتخاب کردی (DE یا US).
- DNS باید ISP خودت را نشان ندهد.
- WebRTC نباید IP واقعی‌ات را نشان بدهد.

اگر کشور عوض شد، یعنی روی Auto کلی هستی یا نود اشتباهی را انتخاب کرده‌ای — برگرد به Manual و همان کشور.

## امنیت — خط قرمزها

- روی نود رایگان **هرگز بانک، صرافی و لاگین حساس** را باز نکن.
- لینک سابسکریپشن و توکن بات را **به هیچ‌کس نفرست** و اسکرین‌شات نکن.
- توکن بات را در هیچ فایلی ننویس؛ فقط در GitHub Secrets.
- اگر لینک لو رفت، توکن بات را در BotFather با `/revoke` عوض کن و لینک‌ها را از یک ریپوی جدید بساز.

## فایل‌ها

| فایل | چیست |
|---|---|
| `fetch.py` | فچر — فقط Python stdlib، بدون وابستگی اضافه |
| `notify.py` | ارسال پیام تلگرام — فقط از Secretها می‌خواند، اگر نباشند بی‌صدا رد می‌شود |
| `de.txt` / `us.txt` | خروجی — سابسکریپشن Base64، هر ۶ ساعت تازه می‌شود |
| `stats.json` | آمار آخرین اجرا — تعداد، منبع، زمان UTC |
| `.github/workflows/update.yml` | ورک‌فلو — هر ۶ ساعت + اجرای دستی، کامیت + پیام تلگرام |
| `README-FA.md` | همین راهنما |

## منابع

- Raydikalx — `verified` و فایل‌های کشوری `Countries/Germany.txt` و `Countries/United_States.txt` — تست HTTP واقعی، سه مرحله‌ای.
- Au1rxx — `free-vpn-subscriptions`، `v2ray-base64.txt` — تست ساعتی؛ فقط Hysteria2 آن (با GeoIP تاییدشده) استفاده می‌شود، چون نام نودهاش کشور را نمی‌گوید.
- GeoIP برای Au1rxx — `ip-api.com/batch`، رایگان و بدون کلید. IPهای Cloudflare anycast برای تعیین کشور استفاده نمی‌شوند.
